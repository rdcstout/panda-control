# Panda Control 0.1.6

- Saved devices found in the Add window now have an **Open** button. Opening one refreshes its address and selects its existing tab.
- Adding a newly discovered device closes the Add window and opens its controls.

Available for macOS Apple silicon, Windows 64-bit, Linux AppImage, and Debian/Ubuntu 64-bit. The macOS download is Developer ID signed and notarized. SHA-256 checksums are included with the downloads.
