# Panda Control 0.1.4

## What's new

- Adds complete Basic and Advanced Panda Control Vent controls matching firmware 0.1.2, including cooldown thresholds, material rules, and two-zone lighting.
- Prevents stale reads or delayed writes from affecting a different device after switching tabs or discovering a changed address.
- Verifies saved settings and immediate vent commands against the device response before reporting success.
- Retries network discovery when a supported device misses the first fast scan.
- Keeps dialogs visible after scrolling, adds desktop keyboard behavior, and preserves proportional square sizing when a window is zoomed.
- Improves offline status, update eligibility, persistence validation, accessibility, and error messages.

## Downloads

- macOS Apple silicon: `Panda-Control-macOS-arm64.dmg`
- Windows 64-bit: `Panda-Control-Windows-x64.exe`
- Linux AppImage: `Panda-Control-Linux-x86_64.AppImage`
- Debian/Ubuntu 64-bit: `Panda-Control-Linux-amd64.deb`

The macOS build is Developer ID signed and notarized by Apple. SHA-256 checksums are included with the release.
