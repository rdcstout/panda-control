# Panda Control 0.1.5

- Fixes Scan skipping devices that had previously been removed. Pressing Scan can now add them back without using Add or entering an IP address.
- Keeps existing devices saved and avoids duplicate entries when scanning again.

Available for macOS Apple silicon, Windows 64-bit, Linux AppImage, and Debian/Ubuntu 64-bit. The macOS download is Developer ID signed and notarized. SHA-256 checksums are included with the downloads.
