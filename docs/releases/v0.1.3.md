# Panda Control 0.1.3

Panda Control is now available for macOS, Windows, and 64-bit x86 Linux.

## What's new

- Adds Linux AppImage and Debian/Ubuntu packages.
- Adds an About panel with manual update checks and a default-on weekly release check. Downloads and installation remain user-controlled.
- Improves recovery when a saved device receives a new IP address after a router or DHCP change.
- Adds macOS Local Network permission guidance to the Add Device window.
- Keeps the Linux window square while it is resized so the interface scales proportionally.

## Downloads

- macOS Apple silicon: `Panda-Control-macOS-arm64.dmg`
- Windows 64-bit: `Panda-Control-Windows-x64.exe`
- Linux AppImage: `Panda-Control-Linux-x86_64.AppImage`
- Debian/Ubuntu 64-bit: `Panda-Control-Linux-amd64.deb`

The macOS build is Developer ID signed and notarized by Apple. SHA-256 checksums are included with the release.
