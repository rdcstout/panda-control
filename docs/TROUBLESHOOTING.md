# Panda Control troubleshooting

[Back to Panda Control](../README.md)

## No devices are found on macOS

Open **System Settings → Privacy & Security → Local Network** and make sure Panda Control is enabled. Then return to Panda Control and press **Scan**.

## A device moved to a new IP address

Press **Scan**. Panda Control matches supported devices by hardware identity and updates the saved address instead of adding a duplicate.

## A device is still unavailable

Confirm the computer and accessory are on the same network, verify the accessory is powered on, and try its IP address through **Add**.
