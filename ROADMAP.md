# Panda Control Roadmap

## Current release

Panda Control 0.1.3 supports normal operational control of Panda Status, Panda Breath, stock Panda Vent, and Panda Control Vent firmware on macOS, Windows, and 64-bit x86 Linux.

The application intentionally begins after factory setup. Wi-Fi onboarding, printer binding, factory reset, and firmware installation remain in each device's own setup interface.

## Future work

- Evaluate additional Panda products only after their operational protocol is mapped and verified on real hardware.
- Continue accessibility, reliability, and platform-compatibility improvements as useful issues are reproduced.
- Keep downloads free and update the stable release links with every published version.

No additional device support is promised until it has passed the same hardware-validation standard as the current integrations.
